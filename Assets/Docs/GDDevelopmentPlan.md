## ЧАСТИНА 1: ПРІОРИТИЗОВАНИЙ ROADMAP

### 🔴 ФАЗА 1: Валюта + Бусти (Тиждень 1-2)

#### 1.1 Currency System (Монети)

**Опис:** Внутрішньоігрова валюта — монети. Гравець заробляє за проходження рівнів, витрачає на бусти.

**Економічний цикл:**
```
Граєш рівень → Заробляєш монети → Витрачаєш на бусти → 
Проходиш складніший рівень → Заробляєш більше → ...
```

**Де заробляти монети:**

| Джерело | Кількість | Коментар |
|---------|-----------|----------|
| Проходження рівня | 50-100 | Залежно від зірок (пізніше) |
| Daily challenge | 300-500 | Велика нагорода за щоденний виклик |
| Щоденний бонус (streak) | 50-200 | Зростає з кожним днем (пізніше) |
| Реклама (rewarded video) | 100-300 | Якщо буде монетизація |

**Що можна купувати за монети:**

| Буст | Ціна (приклад) | Ефект |
|------|----------------|-------|
| Hint (підказка) | 100 монет | Підсвічує оптимальний хід |
| +5 Moves | 80 монет | Додає 5 ходів при поразці |
| Undo (скасування ходу) | 50 монет | Відміняє останній хід |

**UI:**
- На GameView: баланс монет (іконка + число)
- На LoseView: кнопки покупки за монети
- Окремий екран магазину (опціонально, можна додати пізніше)

**Save:** Зберігати баланс монет в PlayerProgressData.

---

#### 1.2 Hint System (Підказки за монети)

**Опис:** Гравець може купити підказку за 100 монет.

**Реалізація:**
- Солвер вже є (A* в LevelGenerator) — потрібно використати для визначення оптимального ходу
- Варіанти:
  - **Highlight:** Підсвічує сегмент + напрямок руху (3 секунди)
  - **Auto-move:** Автоматично виконує один хід (простіший для початку)

**UI:** Кнопка "💡" на GameView. При натисканні → якщо є монети → показує хінт. Якщо немає → пропонує купити.

**Мотивація:** Запобігає frustration quit. Гравець "застряг" → купує хінт → проходить рівень → продовжує грати.

---

#### 1.3 Undo Move (Скасування за монети)

**Опис:** Гравець може відмінити останній хід за 50 монет.

**Реалізація:**
- Зберігати стан матриці кольорів та scroll offset перед кожним ходом
- При натисканні "Undo" → відновлювати попередній стан
- Обмеження: максимальна глибина undo = 3 ходи (щоб не зловживати)

**UI:** Кнопка "↩️" на GameView (поруч з хінтом).

---

#### 1.4 Failure Recovery (Monetize поразку)

**Опис:** Поточна система: LoseView → +5 ходів безкоштовно → без обмежень.

**Проблема:** +5 ходів безкоштовно знецінює складність.

**Покращена версія:**
- 1 безкоштовна спроба (+3 ходи) — кожен рівень
- Далі — за монети (100 монет за +5 ходів)
- Кнопка "+5 Moves" на LoseView показує ціну

**UI на LoseView:**
```
[Restart]  [+5 Moves (100 🪙)]  [Main Menu]
```

### 🟡 ФАЗА 2: Daily Challenge (Тиждень 3)

#### 2.1 Daily Challenge

**Опис:** Щодня один складний рівень з пулу. Велика нагорода за проходження.

**Реалізація:**
- Пул з 30-50 складних рівнів (генерується через LevelGenerator з високою difficulty)
- Щодня: `levelPool[System.DateTime.Now.DayOfYear % pool.Count]`
- Не потрібен сервер — seed-based підхід
- Гравці бачать однаковий рівень того самого дня

**Доступність:**
- Розблоковується на Level 10 (або Level 15)
- На MainMenu: кнопка "Daily Challenge" з іконкою 🔒 та текстом "Unlock at Level X"
- При досягненні Level X → анімація розблокування
- Блокування створює anticipation: "О, є ще один режим, хочу швидше дістатися"

**Нагорода:**
- Виграш: 300-500 монет
- Програш: нічого (або 50 монет як втіша)

**UI:**
- Кнопка на MainMenu (зліва або справа від "Play")
- Таймер "Час до нового виклику: 14:32:05"
- Екран результату: "Daily Challenge Complete! +500 🪙"

### 🟢 ФАЗА 3: Зірки + Прогрес-мапа (Тиждень 4-5)

#### 3.1 Star Rating System (1-3 зірки)

**Опис:** Кожен рівень оцінюється від 1 до 3 зірок.

**Формула (приклад):**
```
MovesLeft = MovesForLevel - MovesUsed
Ratio = MovesLeft / MovesForLevel

3 зірки: Ratio >= 0.5 (використав менше половини ходів)
2 зірки: Ratio >= 0.25
1 зірка: Ratio >= 0 (просто пройшов)
```

**Чому зірки потрібні:**
- Дають мету "проходити ідеально" (mastery)
- Подовжують загальний час гри (перепроходження заради 3 зірок)
- Потрібні для зв'язки з монетами (більше зірок = більше монет)
- Стандарт для puzzle games (90%+ мають зірки)

**Зв'язка з монетами:**
```
1 зірка: 50 монет
2 зірки: 75 монет
3 зірки: 100 монет
```

**UI:**
- На Win екрані: анімація зірок (1 → 2 → 3)
- На Progress Map: зірки під номером рівня

**Save:** Зберігати кількість зірок на кожному рівні в PlayerProgressData.

---

#### 3.2 Stars Economy

**Опис:** Зв'язати зірки з монетами.

**Механіка:**
- За кожен пройдений рівень: 50 + (кількість зірок × 25) монет
- За Daily Challenge: 300 + (кількість зірок × 100) монет
- За перепроходження рівня (отримав більше зірок): різниця в монетах

---

#### 3.3 Progress Map (Карта прогресію)

**Опис:** Візуальна карта з номерами рівнів, зірками, та блокуванням.

**Навіщо без неї не можна:**
- Без мапи гравець бачить тільки "Level 23" — не знає скільки попереду
- Без мапи немає можливості перепроходити рівні (отримати більше зірок)
- Без мапи гра виглядає як prototype для видавця

**Дизайн:**
- Проста лінійна карта (вертикальний скролінг)
- Кожен рівень: номер + 3 зірки (порожні/заповнені)
- Locked → Unlocked → Completed
- Автоматичний скрол до поточного рівня

**UI:**
- Замість кнопки "Play" на MainMenu → відкриває Progress Map
- Або кнопка "Play" → Починає останній незавершений рівень

**Складність реалізації:** Середня (5-7 днів).

### 🔵 ФАЗА 4: Додатковий контент (Тиждень 6-7)

#### 4.1 Level Pool Expansion

**Опис:** Розширення пулу до 150-200 рівнів.

**Стратегія:**
- Використати LevelGenerator для створення 100+ нових рівнів
- Розподілити за складністю відповідно до кривої
- Поточний пул (~69) + нові (100+) = ~170 рівнів

---

#### 4.2 Difficulty Curve Tuning

**Опис:** Налаштування кривої складності для правильного onboarding.

**Крива:**
```
Levels 1-5:    Very Easy (3-5 moves, 2-3 sectors, 2-3 colors)
Levels 6-15:   Easy (5-8 moves, 4 sectors, 3-4 colors)
Levels 16-30:  Medium (8-12 moves, introduce Blocked)
Levels 31-50:  Medium-Hard (10-15 moves, introduce FilterColors)
Levels 51-100: Hard (12-18 moves, introduce Empty segments)
Levels 101+:   Very Hard (15-25 moves, all mechanics)
```

---

#### 4.3 Streak System (Система серій)

**Опис:** Гравець отримує бонуси за щоденне входження.

**Нагороди:**
```
День 1: 50 монет
День 2: 75 монет
День 3: 100 монет
День 4: 125 монет
День 5: 150 монет
День 6: 175 монет
День 7: 300 монет + 1 hint
```

**Правила:**
- Якщо гравець пропустив день → серія скидається до 1
- Показується при вході в гру (popup)

---

#### 4.4 Save System Migration (JSON)

**Опис:** Замінити BinaryFormatter на JSON (JsonUtility або Newtonsoft).

**Чому:**
- BinaryFormatter deprecated
- Не працює на IL2CPP/WebGL
- Має проблеми з безпекою

**Міграція:**
- При першому запуску: спробувати прочитати BinaryFormatter
- Якщо успішно → конвертувати в JSON, зберегти, видалити старий файл
- Далі — тільки JSON

## ЧАСТИНА 4: РИЗИКИ

1. **Balance монет** — якщо монети занадто легкі в заробітку → бусти не коштують нічого. Якщо занадто важкі → гравець фруструється. Потрібен playtest.
2. **Hint solver** — A* solver може бути занадто повільним для складних рівнів. Потрібен таймліміт або спрощений алгоритм для хінтів.
3. **Daily Challenge баланс** — рівні мають бути складнішими за звичайні, але не неможливими.
4. **Progress Map UX** — якщо рівнів 200+, карта може бути занадто довгою. Потрібен smooth scrolling.
5. **BinaryFormatter міграція** — може зламати save існуючих гравців (якщо є бета-тестери).
