#### ✅ 1.5 Hint System — ВІДМІНЕНО

**Причина відміни:** Хінти не підходять до механіки Color Rings.
- На відміну від match-3, де хінт = підказка (один з багатьох можливих ходів),
  тут хінт = готове рішення (A* solver показує оптимальний хід)
- 3-5 хінтів = пройдений рівень без жодного мозкового зусилля
- Гравець не грає, він просто натискає кнопку

**Альтернатива (вже реалізована):** +Moves за монети — краще вирішує проблему frustration:
- Гравець грає САМ
- Докуповує ходи → але все одно вирішує рівень самостійно
- Це "дати додатковий шанс", а не "вирішити за гравця"

#### 1.1 Currency System (Монети)

**Опис:** Внутрішньоігрова валюта — монети. Гравець заробляє за проходження рівнів, витрачає на бусти.

**Економічний цикл:**
```
Граєш рівень → Заробляєш монети → Витрачаєш на бусти → 
Проходиш складніший рівень → Заробляєш більше → ...
```

**Де заробляти монети:**

| Джерело | Кількість | Коментар |
|---------|-----------|----------|
| Проходження рівня | 50-100 | Залежно від зірок (пізніше) |
| Daily challenge | 300-500 | Велика нагорода за щоденний виклик |
| Щоденний бонус (streak) | 50-200 | Зростає з кожним днем (пізніше) |
| Реклама (rewarded video) | 100-300 | Якщо буде монетизація |

**Що можна купувати за монети:**

| Буст | Ціна | Ефект |
|------|------|-------|
| Undo (скасування ходу) | 60 монет | Відміняє останній хід |
| +3 Moves | 80 монет | Додає 3 ходи при поразці |

**UI:**
- На GameView: баланс монет (іконка + число)
- На LoseView: кнопки покупки за монети
- Окремий екран магазину (опціонально, можна додати пізніше)

**Save:** Зберігати баланс монет в PlayerProgressData.

---

#### 1.2 Hint System (Підказки за монети)

**Опис:** Гравець може купити підказку за 100 монет.

**Реалізація:**
- Солвер вже є (A* в LevelGenerator) — потрібно використати для визначення оптимального ходу
- Варіанти:
  - **Highlight:** Підсвічує сегмент + напрямок руху (3 секунди)
  - **Auto-move:** Автоматично виконує один хід (простіший для початку)

**UI:** Кнопка "💡" на GameView. При натисканні → якщо є монети → показує хінт. Якщо немає → пропонує купити.

**Мотивація:** Запобігає frustration quit. Гравець "застряг" → купує хінт → проходить рівень → продовжує грати.

---

#### 1.3 Undo Move (Скасування за монети)

**Опис:** Гравець може відмінити останній хід за 60 монет.

**Реалізація:**
- Зберігати стан матриці кольорів та scroll offset перед кожним ходом
- При натисканні "Undo" → відновлювати попередній стан
- Обмеження: максимальна глибина undo = 3 ходи (щоб не зловживати)

**UI:** Кнопка "↩️" на GameView (поруч з хінтом).

---

#### 1.4 Failure Recovery (Monetize поразку)

**Опис:** Поточна система: LoseView → +5 ходів безкоштовно → без обмежень.

**Проблема:** +5 ходів безкоштовно знецінює складність.

**Покращена версія:**
- 1 безкоштовна спроба (+3 ходи) — кожен рівень
- Далі — за монети (80 монет за +3 ходи)
- Кнопка "+5 Moves" на LoseView показує ціну

**UI на LoseView:**
```
[Restart]  [+5 Moves (100 🪙)]  [Main Menu]
```

### 🟢 ФАЗА 3: Зірки + Прогрес-мапа (Тиждень 4-5) — ✅ ВИКОНАНО

#### ✅ 3.1 Star Rating System (2-tier: ✓ / ⭐) — ВИКОНАНО

#### ✅ 3.2 Progress Map (Perfect Map) — ВИКОНАНО

**Концепція:** Список пройдених рівнів зі статусами (✓ або ⭐).
- Тап на рівень → Replay для отримання ⭐
- Прогрес-бар для нагороди (кожні 3 ⭐ = бонус)
- Ескалація нагород (економіка буде доопрацьована пізніше)

**Опис:** Дві оцінки для кожного рівня.

| Статус | Критерій | Вигляд |
|--------|----------|--------|
| **Пройдений** | Будь-яка кількість ходів (≤ ліміту) | ✓ |
| **Ідеально** | ≤ solver (мінімальна кількість ходів) | ⭐ |

**Використання A* solver:**
- Solver знає мінімальну кількість ходів для кожного рівня
- Поріг для ⭐: `moves_used ≤ solver_moves`

**Чому зірки потрібні:**
- Дають мету "проходити ідеально" (mastery)
- Подовжують загальний час гри (перепроходження заради ⭐)
- Потрібні для зв'язки з монетами
- На Progress Map видно прогрес

**Зв'язка з монетами (звичайні рівні):**
```
✓: 30 монет (базова нагорода за проходження)
⭐: +30/+50/+75/+100 монет (залежно від діапазону рівня)
```

**Діапазони нагород за ⭐:**
| Діапазон | Базова (✓) | Бонус за ⭐ | Всього за ⭐ |
|----------|------------|-------------|-------------|
| 1-30 | 30 | +30 | 60 |
| 31-60 | 30 | +50 | 80 |
| 61-100 | 30 | +75 | 105 |
| 101-150 | 30 | +100 | 130 |

**UI:**
- На Win екрані: якщо ⭐ → анімація зірки
- На Progress Map: ✓ або ⭐ під номером рівня

**Save:** Зберігати стан (✓ або ⭐) на кожному рівні в PlayerProgressData.

#### 3.3 Progress Map (Карта прогресію)

**Опис:** Візуальна карта з номерами рівнів, зірками, та блокуванням.

**Навіщо без неї не можна:**
- Без мапи гравець бачить тільки "Level 23" — не знає скільки попереду
- Без мапи немає можливості перепроходити рівні (отримати більше зірок)
- Без мапи гра виглядає як prototype для видавця

**Дизайн:**
- Проста лінійна карта (вертикальний скролінг)
- Кожен рівень: номер + 3 зірки (порожні/заповнені)
- Locked → Unlocked → Completed
- Автоматичний скрол до поточного рівня

**UI:**
- Замість кнопки "Play" на MainMenu → відкриває Progress Map
- Або кнопка "Play" → Починає останній незавершений рівень

**Складність реалізації:** Середня (5-7 днів).
