# Система генерації та оцінки складності рівнів (Level Design Logic)

Цей документ описує математичну модель, алгоритми та поточний стан системи автоматизованого створення рівнів гри "Color Rings".

## 1. Поточний стан (Current Status)
На даний момент реалізовано ядро системи:
*   **LevelState.cs**: Математична модель (матриця кольорів), що підтримує операції обертання та слайду.
*   **LevelSolver.cs**: Використовує алгоритм **A* (A-Star)** для знаходження найкоротшого шляху. Враховує заблоковані сегменти та фільтри кольорів на аренах.
*   **LevelGenerator.cs**: Асинхронний генератор, що використовує "Reverse Scramble" та фонові потоки (`Task.Run`) для запобігання зависань Unity.
*   **LevelGeneratorWindow.cs**: Вікно редактора з візуалізацією прев'ю (Painter2D), налаштуваннями діапазонів та кнопкою збереження в `.asset`.

## 2. Алгоритм та логіка

### Solver (A* Engine)
*   **Евристика**: Сума відсутніх сегментів до повного заповнення кільця одним кольором.
*   **Оптимізація**: Використовує `SortedList` як чергу пріоритетів для швидкого пошуку оптимального ходу.
*   **Запобіжник**: Ліміт у 50,000 ітерацій для уникнення вічних циклів на занадто складних конфігураціях.

### Генератор
*   **Scramble**: Виконує 5-15 випадкових валідних ходів від зібраного стану.
*   **Thread Safety**: Використовує `System.Random` для роботи в бекграунд-потоці. Створення `ScriptableObject` винесено в основний потік після завершення розрахунків.

## 3. Реалізовані обмеження (Constraints)
1.  **Uniformity**: Кількість сегментів однакова для всіх кіл на рівні.
2.  **Gap Rule**: Між слайд-аренами завжди є мінімум 1 вільний сектор.
3.  **Locked Segments**: 
    *   Якщо сегмент заблокований (`SegmentStatus.Blocked`), він блокує можливість виконання слайду через цю арену.
    *   Враховується при розрахунку складності.
4.  **Async UI**: Інтерфейс залишається чутливим під час генерації; є індикація прогресу.

## 4. План на наступну сесію (Next Steps)

### А. Розширення налаштувань UI
Потрібно додати можливість вибору дозволених статусів у вікні `Level Generator`:
*   **Чекбокси для сегментів**: [ ] Default, [ ] Blocked.
*   **Чекбокси для арен**: [ ] Default, [ ] FilterColors.
*   **Ймовірність**: Повзунок для шансу появи заблокованого сегмента (зараз захардкоджено 10%).

### Б. Логіка FilterColors
*   Доопрацювати генератор, щоб він міг випадковим чином призначати статус `FilterColors` аренам та вибирати для них список дозволених кольорів.
*   Забезпечити, щоб при заплутуванні (scramble) враховувалися ці фільтри.

### В. Покращення візуалізації
*   Додати відображення індексів секторів та кіл у прев'ю.
*   Візуально виділяти арени з фільтрами (наприклад, іншим кольором рамки).
