# Currency Balance Document: Color Rings

---

## 1. ЗАГАЛЬНІ ПРИНЦИПИ

**Ціль:** Гравець МАЄ мати потребу в монетах. Не повинен бути профіцит, де монети "ні на що витрачати."

**Філософія:**
- Легкі рівні → гравець заробляє → накопичує запас
- Складні рівні → гравець витрачає → запас тане
- Мета: щоб на рівні 50+ гравець завжди відчував "малувато монет"

## 2. ДЖЕРЕЛА ДОХОДУ (ЗАРОБІТОК)

### 2.1 Проходження рівня (основне джерело)

| Результат | Нагорода | Коментар |
|-----------|----------|----------|
| Виграш | 50 монет | Фіксовано (пізніше: залежно від зірок) |
| Програш | 0 монет | Нічого |

### 2.2 Daily Challenge (кумулятивні нагороди)

| Зірки | Монети | Undo | Загалом |
|-------|--------|------|---------|
| 1⭐ | 50 | — | 50 🪙 |
| 2⭐ | 150 | 1 | 150 🪙 + 1 Undo |
| 3⭐ | 350 | 3 | 350 🪙 + 3 Undo |

При перепроходженні: отримуєш різницю.

**Приклад:**
```
Спроба 1: 1⭐ → 50 монет
Спроба 2: 2⭐ → +100 монет + 1 Undo
Спроба 3: 3⭐ → +200 монет + 2 Undo
Загалом: 350 монет + 3 Undo
```

### 2.3 Щоденний бонус (streak) — ФАЗА 4

| День поспіль | Нагорода |
|-------------|----------|
| День 1 | 30 монет |
| День 2 | 40 монет |

### 2.4 Загальний дохід за сесію

| Сценарій | Рівні | Daily | Streak | Загалом |

| З daily + streak (день 7) | 10 × 50 | 200 | 100 | **800** |

## 3. ВИТРАТИ (БУСТИ)

### 3.1 Бусти та їх вартість

| Буст | Ціна | Ефект | Обмеження |
|------|------|-------|-----------|
| **Undo** | 80 монет | Скасовує останній хід | Макс. 3 undo на рівень |

## 4. ЕКОНОМІЧНА МОДЕЛЬ — СЕСІЯ

### 4.1 Сценарій: Легкі рівні (1-15)

Гравець проходить все з першого разу, не витрачає бусти.

| | |
|---|---|
| Заробіток | 10 × 50 = **500** |
| Витрати | 0 |
| **Чистий прибуток** | **+500** |
| Після 3 сесій | **1500 монет** (накопичується) |

**Проблема:** Занадто багато монет. Але це нормально — ранні рівні легкі, гравець "відпочиває" і накопичує.

### 4.2 Сценарій: Середні рівні (16-40)

Гравець починає застрягати: 1-2 +3 moves на сесію.

| | |
|---|---|
| Заробіток | 10 × 50 = **500** |
| Витрати | 2 +3 moves (200) = **200** |
| **Чистий прибуток** | **+300** |
| Після 5 сесій | **1500 монет** (запас є, але повільно зростає) |

### 4.3 Сценарій: Складні рівні (41-80)

Гравець застрягає часто: 2-3 +3 moves, 1-2 undo на сесію.

| | |
|---|---|
| Заробіток | 10 × 50 = **500** |
| Витрати | 3 +3 moves (300) + 2 undo (160) = **460** |
| **Чистий прибуток** | **+40** (майже в нуль) |
| Після 5 сесій | Запас стабільний: +200 монет |

### 4.4 Сценарій: Дуже складні рівні (81+)

Гравець постійно застрягає: 3 +3 moves, 2-3 undo.

| | |
|---|---|
| Заробіток | 10 × 50 = **500** |
| Витрати | 3 +3 moves (300) + 3 undo (240) = **540** |
| **Чистий прибуток** | **-40** (легкий дефіцит) |
| Після 3 сесій | Запас тане: -120 монет |

## 5. ГРАФІК НАКОПИЧЕННЯ/ВИТРАТ

```
Рівень:    1    10    20    30    40    50    60    70    80
           │     │     │     │     │     │     │     │     │
Баланс:   500  2500  4500  6000  6500  6800  6900  7000  7000
           ▲     ▲     ▲     ▲     ▲     ▲     →     →     →
         Наріст Наріст Наріст Наріст Повільний стабілізація
         монет  монет  монет  монет  наростання
```

**Ключовий момент:** Без хінтів економіка стає більш здоровою.
Гравець накопичує на легких рівнях → на складних витрачає менше → запас стабілізується.
На рівні 50+ гравець приблизно в нулі (складні рівні з'їдають те, що заробив).

---

## 6. АНТИ-ПРОФІЦІТ МЕХАНІКИ

### 6.1 Зростання складності (основна механіка)
- Чим складніший рівень → тим більше хінтів/бусти потрібно
- Гравець не може просто "накопичити і сидіти" — складні рівні з'їдають запас

### 6.2 Обмеження на бусти
- Hint: макс. 3 на рівень (не можна витратити все на одному)
- +3 Moves: макс. 2 на рівень
- Undo: макс. 3 на рівень

### 6.3 Безкоштовна допомога = мінімальна
- +3 Moves безкоштовно: тільки 1 раз на рівень
- Далі — тільки за монети

### 6.4 Бонусні Undo з Daily Challenge
- Гравець отримує 1-3 Undo за зірки в daily
- Бонусні Undo зберігаються в BonusUndos
- При використанні undo: спочатку бонусні, потім за монети
- Це створює цикл: daily → отримав undo → використав → хоче більше → грає daily знову

## 7. ПСИХОЛОГІЯ ВИТРАТ

### 7.1 Коли гравець ВТРАЧАЄ монети (найкращий момент)
- При поразці (LoseView) — гравець фрустрований і хоче продовжити
- Коли бачить "ще один хід і виграв" — хоче купити +3 moves

### 7.2 Коли гравець ЗАРОБЛЯЄ монети (найгірший момент для витрат)
- Після виграшу — гравець задоволений, не хоче витрачати
- На MainMenu — гравець ще не знає скільки буде коштувати наступний рівень

### 7.3 Рекомендація по UI
- Показувати баланс на GameView (щоб гравець бачив "скільки у мене є")
- На LoseView: кнопки покупки з ціною (щоб гравець бачив "скільки це коштує")
- Не ховати магазин — гравець має знати що можна купити

## 9. МАЙБУТНІ ЗМІНИ (коли будуть зірки)

### 9.1 Нагорода за зірки

| Зірки | Монети за рівень | Коментар |
|-------|------------------|----------|
| 1 зірка | 40 | Базова нагорода |
| 2 зірки | 60 | +50% до бази |
| 3 зірки | 100 | +150% до бази |

### 9.2 Перепроходження заради зірок
- Якщо гравець пройшов рівень з 1 зіркою → може перепройти заради 3
- За перепроходження: різниця в монетах (100 - 40 = 60 додатково)
- Це створює мотивацію перепроходити + витрачати час

### 9.3 Прогрес-мапа + зірки
- На мапі видно: "Цей рівень пройдений з 1 зіркою"
- Гравець може повернутися і спробувати краще
- Це подовжує загальний час гри
