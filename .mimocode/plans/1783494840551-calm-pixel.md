# План: Повна переробка Level 1 та туторіалу

## Концепція

Переробити Level 1 так, щоб гравець:
1. Окремо вивчив механіку обертання з підсвіткою (простіше)
2. Окремо вивчив слайд-механіку з підсвіткою (складніше)
3. Побачив готову смугу (win condition візуально)
4. Самостійно виконав 2 ходи для завершення решти 2 смуг
5. Отримав підказку якщо спробує зламати готову смугу

---

## Частина 1: Конфіг Level 1

### Дизайн рівня

3 кола, 4 сегменти кожне, 2 кольори (Red=2, Blue=3):

```
Смуга 0 (готова):  [Red] [Red] [Red] [Red]  ← вже виграна
Смуга 1:           [Red] [Blue] [Red] [Blue] ← потребує 1 слайд
Смуга 2:           [Blue] [Red] [Blue] [Red] ← потребує 1 слайд
```

Slide areas:
- Area 0: sector 0, connecting circle 1→circle 2 (для слайду між смугами 1 та 2)
- Area 1: sector 2, connecting circle 0→circle 1 (для слайду між смугами 0 та 1)

Optimal: 2 ходи (2 слайди)
Moves: 15 (generous buffer)

### Файли для зміни

| Файл | Дія |
|------|-----|
| `Assets/ScriptableObjects/Levels/1/LevelConfig_lvl_ 1.asset` | Переробити: 3 circleConfigs, 2 slideAreaConfigs, _difficulty=8, _averageMoves=10, _difficultyMultiplier=1.5, new solutionPath |
| `Assets/ScriptableObjects/Levels/1/1.asset` | Новий CircleConfig: Red, Red, Red, Red |
| `Assets/ScriptableObjects/Levels/1/2.asset` | Новий CircleConfig: Red, Blue, Red, Blue |
| (новий файл) `Assets/ScriptableObjects/Levels/1/3.asset` | CircleConfig: Blue, Red, Blue, Red |

**Важливо:** solutionPath міститиме тільки слайди (бо rotate тут не потрібен для optimal).

## Частина 2: Нові tutorial state класи

### 2a. ShowRotationHighlightState

**Новий файл:** `Assets/Feature/TutorialModule/Scripts/Tutorials/TutorialStates/FirstTutorialStates/ShowRotationHighlightState.cs`

Що робить:
- Підсвічує сегменти однієї смуги поза slide area (ті що належать кільцю, але не в зоні слайду)
- Показує текст: "Swipe left or right on a ring to rotate its segments"
- Завершується тапом

Залежності: `StripModel`, `SlideAreaModel`, `IViewService`, `TutorialViewModel`, `ILocalizationService`, `IInputService`

Реалізація підсвітки — аналог `ShowBlockedSegmentsState`:
```csharp
// Знайти сегменти поза slide area, підвищити sorting order
foreach (var segment in allSegments) {
    if (!segmentsInAreas.Contains(segment)) {
        segment.SetSortingOrder(10000);
    }
}
```

### 2b. ShowSlideAreaHighlightState

**Новий файл:** `Assets/Feature/TutorialModule/Scripts/Tutorials/TutorialStates/FirstTutorialStates/ShowSlideAreaHighlightState.cs`

Що робить:
- Підсвічує сегменти в slide area (підвищує sorting order, як BlockedSegmentsState)
- Показує текст: "Drag these segments up or down to move them between rings"
- Завершується тапом

Залежності: `SlideAreaModel`, `IViewService`, `TutorialViewModel`, `ILocalizationService`, `IInputService`

### 2c. ShowWinConditionState

**Новий файл:** `Assets/Feature/TutorialModule/Scripts/Tutorials/TutorialStates/FirstTutorialStates/ShowWinConditionState.cs`

Що робить:
- Підсвічує готову смугу (смуга 0 — всі Red)
- Показує текст: "This strip is complete! Make the other strips the same color to win"
- Завершується тапом

### 2d. GuidedMoveState (3 екземпляри)

**Новий файл:** `Assets/Feature/TutorialModule/Scripts/Tutorials/TutorialStates/FirstTutorialStates/GuidedMoveState.cs`

Що робить:
- Показує finger hint для конкретного ходу
- Завершується тільки після реального ходу (`MoveTrackModel.OnMovesChanged`)
- Параметри: stripIndex, direction (horizontal/vertical), sectorIndex

3 екземпляри в tutorial:
1. Слайд смугою 1 вгору (щоб вирівняти кольори)
2. Слайд смугою 2 вниз
3. (Якщо потрібен rotate — обертання кільця)

### 2e. ProtectiveHintState

**Новий файл:** `Assets/Feature/TutorialModule/Scripts/Tutorials/TutorialStates/FirstTutorialStates/ProtectiveHintState.cs`

Це НЕ окремий стан, а поведінка яка активна під час guided moves.

Що робить:
- Якщо гравець намагається обернути кільце де смуга вже готова → показати попередження
- Якщо гравець робить слайд через готову смугу → показати попередження

Реалізація:
- Підписатися на `_stripModel.OnStripCompletedStatusChanged`
- Перед ходом перевіряти чи не зачеплена готова смуга
- Якщо так — показати текст "This strip is complete — don't break it!" і відкотити хід (Undo)

## Частина 3: Оновлення TutorialFactory

**Файл:** `Assets/Feature/TutorialModule/Scripts/Factory/TutorialFactory.cs`

Додати новий метод:
```csharp
private List<ITutorialState> GetStatesForFirstTutorial() {
    var states = new List<ITutorialState>();
    // Навчальна частина (просте → складне)
    states.Add(_container.Instantiate<ShowRotationHighlightState>());   // Крок 1: rotation
    states.Add(_container.Instantiate<ShowSlideAreaHighlightState>());  // Крок 2: slide area
    states.Add(_container.Instantiate<ShowWinConditionState>());        // Крок 3: win condition
    // Практична частина
    states.Add(_container.Instantiate<GuidedMoveState>());             // Крок 4: guided slide 1
    states.Add(_container.Instantiate<GuidedMoveState>());             // Крок 5: guided slide 2
    return states;
}
```

## Верифікація

1. Запустити Level 1 — побачити 3 смуги, одна готова
2. Туторіал: rotation підсвічується → текст → тап
3. Туторіал: slide area підсвічується → текст → тап
4. Туторіал: win condition показується → текст → тап
5. Guided moves: finger hint → гравець робить реальний хід → наступний крок
6. Якщо гравець ламає готову смугу → попередження + undo
7. Після завершення → win screen
8. Повторний вхід на L1 → туторіал НЕ показується
