# Plan: Allow Horizontal Strip Drag from Slide Zone Segments

## Problem
When a segment is in a slide zone, dragging it horizontally does nothing. The user wants horizontal dragging to move the strip (like normal strip rotation), while vertical dragging should still slide segments within the zone.

## Root Cause
In `SlideSegmentService.OnPointerDown()`, `IsSlideActive = true` is set **immediately** when a slide area is found. This blocks `StripRotationService` from starting strip rotation, because it checks `IsSlideActive` in both `OnPointerDown()` and `Tick()`.

## Solution: Drag Direction Service + Model + Event-Based System

Create `DragDirectionService` + `DragDirectionModel` in InputModule. Service detects direction, writes to Model. `SlideSegmentService` and `StripRotationService` subscribe to Model events.

## New Files

### 1. `Assets/Feature/InputModule/Scripts/DragDirectionModel.cs`

```csharp
using System;

namespace Feature.InputModule.Scripts {
    public enum DragDirection { None, Horizontal, Vertical }

    public class DragDirectionModel {
        public event Action<DragDirection> OnDirectionDetected;

        public void DetectDirection(DragDirection direction) {
            OnDirectionDetected?.Invoke(direction);
        }
    }
}
```

### 2. `Assets/Feature/InputModule/Scripts/DragDirectionService.cs`

```csharp
using UnityEngine;
using Zenject;

namespace Feature.InputModule.Scripts {
    public class DragDirectionService : IDragDirectionService, ITickable {
        private const float DRAG_THRESHOLD = 0.05f;

        private readonly IInputService _inputService;
        private readonly ICameraService _cameraService;
        private readonly DragDirectionModel _model;

        private Vector2 _startWorldPos;
        private bool _isTracking;

        public DragDirectionService(IInputService inputService, ICameraService cameraService, DragDirectionModel model) {
            _inputService = inputService;
            _cameraService = cameraService;
            _model = model;
        }

        public void Reset() {
            _isTracking = false;
        }

        public void StartTracking(Vector2 startWorldPos) {
            _startWorldPos = startWorldPos;
            _isTracking = true;
        }

        public void Tick() {
            if (!_inputService.IsPointerPressed || !_isTracking)
                return;

            Vector3 worldPos = GetWorldPosition();
            float deltaX = Mathf.Abs(worldPos.x - _startWorldPos.x);
            float deltaY = Mathf.Abs(worldPos.y - _startWorldPos.y);

            if (deltaX > DRAG_THRESHOLD || deltaY > DRAG_THRESHOLD) {
                var direction = deltaX > deltaY ? DragDirection.Horizontal : DragDirection.Vertical;
                _model.DetectDirection(direction);
                _isTracking = false;
            }
        }

        private Vector3 GetWorldPosition() {
            var camera = _cameraService.CameraObject ?? Camera.main;
            Vector2 screenPos = _inputService.PointerPosition;
            Vector3 worldPos = camera.ScreenToWorldPoint(new Vector3(screenPos.x, screenPos.y, -camera.transform.position.z));
            worldPos.z = 0;
            return worldPos;
        }
    }
}
```

### 5. `Assets/Feature/SlideAreaModule/Scripts/SlideSegmentService.cs`

**Changes:**
- Inject `IDragDirectionService` and `DragDirectionModel`
- In `OnPointerDown()` → `TrySlideSegments()`:
  - When slide area found: store `_startX = worldPos.x`, call `_dragDirectionService.StartTracking(worldPos)` instead of immediately setting `IsSlideActive = true`

- In `Tick()`: Only process vertical movement (direction already determined)
- In `OnPointerUp()`: Call `_dragDirectionService.Reset()`

## Execution Flow

### Horizontal drag from slide zone:
1. PointerDown → both services find their targets, call `StartTracking()`
2. Tick → `DragDirectionService` detects `deltaX > deltaY` → writes `Horizontal` to `DragDirectionModel`
3. `DragDirectionModel.OnDirectionDetected` fires
4. `SlideSegmentService` receives event → cancels slide (`_activeArea = null`, `IsSlideActive = false`)
5. `StripRotationService.Tick()` → `IsSlideActive = false` → proceeds with strip rotation

### Vertical drag from slide zone:
1. PointerDown → same
2. Tick → `DragDirectionService` detects `deltaY > deltaX` → writes `Vertical` to model
3. `SlideSegmentService` receives event → confirms slide (`IsSlideActive = true`)
4. `StripRotationService.Tick()` → `IsSlideActive = true` → returns
