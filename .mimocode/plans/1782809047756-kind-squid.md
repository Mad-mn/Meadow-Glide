# План: Міграція системи збереження з BinaryFormatter на JSON

## Контекст

Поточна система збереження використовує `BinaryFormatter` — deprecated, insecure, не працює на IL2CPP/WebGL. Потрібно замінити на JSON-серіалізацію.

## Ключові обмеження

- **`JsonUtility` (Unity built-in) НЕ підтримує `Dictionary<>` та `HashSet<>`** — а наші моделі (`PlayerProgressData`, `PlayerInventoryData`) використовують обидва типи
- Рішення: додати `com.unity.nuget.newtonsoft-json` через UPM

## Структура збережень

| Тип | Файл | Ключові типи полів |
|-----|------|---------------------|
| `PlayerProgressData` | `playerprogress_save.dat` | `int`, `Dictionary<int, LevelCompletionData>`, `HashSet<int>` |
| `PlayerSettingsData` | `settings_save.dat` | `bool`, `Language` (enum) |
| `PlayerInventoryData` | `playerinventory_save.dat` | `Dictionary<ResourceType, int>` |
| `DailyChallengeData` | `dailychallenge_save.dat` | `string`, `int` |

## Файли для зміни

## Кроки реалізації

### Крок 1: Додати Newtonsoft.Json

Додати в `Packages/manifest.json`:
```json
"com.unity.nuget.newtonsoft-json": "3.2.1"
```

### Крок 2: Оновити SaveDataService.cs

Замінити `BinaryFormatter` на `JsonConvert`:

```csharp
using Newtonsoft.Json;
// замість:
// using System.Runtime.Serialization.Formatters.Binary;

// LoadFromDisk<T>:
string json = File.ReadAllText(path);
return JsonConvert.DeserializeObject<T>(json);

// SaveToDisk:
string json = JsonConvert.SerializeObject(data, Formatting.Indented);
File.WriteAllText(path, json);
```

**Зміна розширення файлів**: з `.dat` на `.json` (в методі `GetPath`).

### Крок 3: Міграція існуючих збережень

Додати в `SaveDataService` метод міграції, який при завантаженні перевіряє наявність старих `.dat` файлів:

```csharp
private T LoadFromDisk<T>(SaveDataType type) where T : ISaveData, new()
{
    string jsonPath = GetPath(type);        // .json
    string legacyPath = GetLegacyPath(type); // .dat

    // 1. Спробувати завантажити з .json
    if (File.Exists(jsonPath))
    {
        string json = File.ReadAllText(jsonPath);
        return JsonConvert.DeserializeObject<T>(json);
    }

    // 2. Мігрувати з .dat (BinaryFormatter) -> .json
    if (File.Exists(legacyPath))
    {
        return MigrateLegacySave<T>(type, legacyPath);
    }

    // 3. Створити новий
    return new T();
}
```

Метод міграції:
```csharp
private T MigrateLegacySave<T>(SaveDataType type, string legacyPath) where T : ISaveData, new()
{
    try
    {
        BinaryFormatter formatter = new BinaryFormatter();
        using (FileStream stream = new FileStream(legacyPath, FileMode.Open))
        {
            var data = (T)formatter.Deserialize(stream);
            // Зберегти в новому форматі
            SaveToDisk(type, data);
            // Видалити старий файл
            File.Delete(legacyPath);
            Debug.Log($"Migrated {type} from BinaryFormatter to JSON.");
            return data;
        }
    }
    catch (Exception e)
    {
        Debug.LogError($"Failed to migrate {type}: {e.Message}. Using defaults.");
        return new T();
    }
}
```

### Крок 4: Оновити ISaveData.cs

Оновити коментар — `[Serializable]` більше не обов'язковий для JSON, але залишаємо для зворотної сумісності:

```csharp
public interface ISaveData
{
    // [Serializable] attribute is kept for legacy compatibility.
    // Json.NET serializes public fields/properties regardless.
}
```

### Крок 5: Оновити SaveDataEditor.cs

Змінити патерн пошуку файлів:
```csharp
// Було:
string[] files = Directory.GetFiles(Application.persistentDataPath, "*.dat");

// Стало:
string[] files = Directory.GetFiles(Application.persistentDataPath, "*.json");
```

Також видалити застарі `.dat` файли (опціонально).

## Верифікація

1. Відкрити Unity, переконатися що проєкт компілюється без помилок
2. Запустити гру — перевірити що збереження працює (прогрес рівнів, налаштування, інвентар)
3. Перевірити що нові файли мають розширення `.json`
4. Перевірити міграцію: покласти старий `.dat` файл — він має конвертуватися в `.json` і видалитися
5. Перевірити Clear All Saves — видаляє `.json` файли

## Ризики

- **Наявні користувачі**: старі `.dat` файли не будуть прочитані без міграції — міграційний код вирішує це
- **Newtonsoft.Json size**: ~300KB додатково — прийнятно для мобільного проєкту
- **`BinaryFormatter` залишається в проєкті** (тільки для міграції) — можна видалити через N версій, коли міграція більше не потрібна
